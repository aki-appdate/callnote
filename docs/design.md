# CallNote デザイン方針

## 使う人と場面
- **オペレーター**：ヘッドセットをつけたまま、電話を切った数秒で結果を残し、すぐ次の番号へ。画面は見るより「押す」。
- **SV**：朝会の前に、昨日〜今週の数字とつまずきを確かめ、メンバーに一言かける。数字を読み比べる。

## 性格を表す3語
**速い・迷わない・数字に正直**

## 見た目の決まり
- **たとえ**：紙の架電リストに蛍光ペンを引く感覚。黒いインクと、要所だけの黄色いマーカー。
- **色**：墨（`ink`）を主役にして、押すボタンも墨。アクセントは蛍光マーカーの黄（`marker`）を「いま選んでいるもの・今日やること」だけに使う。赤（`bad`）は「予定超過」など本当に遅れているものだけ。青は使わない。
- **上部のバー**：アプリ画面は墨色のバー（操作盤の印象）。紹介ページの冒頭も墨色。
- **書体**：本文は Noto Sans JP。数字・時刻・電話番号は JetBrains Mono（等幅）で桁をそろえる。大きな集計値（KPI）は読みやすさを優先して Noto Sans JP の太字（プロポーショナル）。
- **形**：角丸は小さく（4〜6px）。箱を並べるより、罫線（1px）で区切った表・リストで見せる。影は使わない（ダイアログだけ）。
- **密度**：一覧は詰める（1行で会社名・業種・予定日まで）。記録欄はゆったり、押す場所は大きく。
- **文字の段階**：見出し 20/16px・本文 14px・補足 12px・ラベル 11px（字間を少し広げる）。
- **状態**：選択中＝左に黄色の太線＋薄い黄色。押せない＝薄く＋カーソル禁止。読み込み中・空・エラーは文章で何が起きているかと次の行動を書く。
- **アイコン**：インラインSVG、線の太さ1.75で統一。絵文字は使わない。
- **AIの印**：キラキラ（✧）は使わない。蛍光ペンをひと引きした黄色の線（`MarkerMark`）。AIは「メモに線を引いて要点を拾う係」で、決めるのは人、という役割をそのまま形にする。読み込み中は線がゆっくり明滅する（回転させない）。
- **蛍光ペンを引いた文字**（`Hl`）：文字の下半分に黄色。見出しの結論、集計のアポ数、AIが判断の決め手にしたメモの言葉だけに使う。1画面で引きすぎない。
- **色だけに頼らない**：「超過」「平均より高い」など、色の横に必ず文字か記号を添える。
- **速さのための工夫**：結果ボタンに 1〜6 の数字キーを割り当てる（メモ欄の外で押すと選べる）。

## グラフ
- 1系列は1色（墨の濃いグレー `chart`）。同数の1位はどれも濃くする。強調したい1本だけ `marker` や墨、残りは薄いグレー。
- 棒は24px以下・先端だけ4px丸め。目盛り線は1pxの実線。値は文字色で書く。各グラフに「表で見る」を付ける。

## 画面ごとの組み立て（ほかのアプリと同じ型にしない）
- **紹介ページ**：冒頭は墨の面に「走り書きのメモ（決め手の言葉に線）→ AIの整理」の実物。その下は課題を箇条書きにせず、**同じ1本の電話を「これまでの手入力の記録」と「CallNoteの記録」で1行ずつ比べる表**（項目＝メモ・次に電話する日・断りの理由。左の番号が現場のつまずき）。AIの決まりは架電リストの確認欄のような**チェック欄つきの罫線リスト**。最後は2×2の表ではなく、**奥付のような1列の罫線**で作り手・技術・ソースコードを書く。
- **SVダッシュボード**：数字の帯を上に横並びにしない。右の欄に**紙の集計欄**（アポ数に線、残りは「項目……数字」で縦に読み下す）と**予定日を過ぎたフォロー（全件・古い順。まず5件、残りは「残り◯件も見る」で開く。途中で切れた行を見せない）**を置き、左の広い欄の先頭に**朝会メモ**。朝会メモは墨の帯ではなく、白い紙に墨の太線の見出し。気づきは3列に並べず上から1件ずつ、根拠は番号ボタンではなく**架電ログの該当行をそのまま抜き出し、決め手の言葉に線を引いて**見せる（行を押すと全文）。打ち手は四角いチェック欄つき。
- **スマホ**：上のバーは2段・100px以下に収める（「データを初期化」はアイコンだけ）。デモの断り書きはバーの外に置き、スクロールで隠れてよい。
